# Taper Check — Weekly Quantity Verification

A mobile-friendly React + Vite verification tool for taper quantity calculations.

## Workflow
For each taper period, the pharmacist selects or manually enters:
1. Prescribed daily dose in mg.
2. Tablet/capsule strength in mg.
3. Duration in weeks.

The tool calculates:
- Tablets/capsules required per day.
- Quantity required for each taper period.
- Total taper duration in weeks and days.
- Total quantity across all periods.

Preset suggestions are included for common values while still allowing manual entry.

## Example
35 mg/day using 5 mg tablets for 1 week:
- 35 ÷ 5 = 7 tablets/day
- 7 × 7 days = 49 tablets for that period

## Disclaimer
This tool is intended only as a verification tool and for calculation of the total quantity.
It does not provide medical advice, diagnosis, treatment recommendations, or determine whether
a taper is clinically appropriate. Always verify the final schedule and quantity against the
authorized prescription and applicable clinical instructions.
